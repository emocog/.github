# emocog/.github (PUBLIC)

조직 저장소에 공통으로 쓰는 이슈 템플릿, 풀 리퀘스트 템플릿과 같은 repo cross GitHub 자산을 관리합니다.

개별 저장소가 같은 종류의 파일을 직접 두지 않으면, GitHub에서 이 저장소의 파일을 기본값으로 사용합니다.

*개별 저장소에 같은 종류의 파일이 있으면 그 파일이 우선됩니다.*

## 자산 위치

- 이슈 템플릿: `.github/ISSUE_TEMPLATE/{issue_kind}.yml`
- 풀 리퀘스트 템플릿: `.github/PULL_REQUEST_TEMPLATE.md`

이슈 템플릿에 지정한 라벨을 사용하기 위해서는 템플릿을 사용하는 각 저장소에 같은 이름의 라벨이 존재해야 합니다.

## 공개 저장소 주의

이 저장소는 **public**입니다. 민감 정보를 넣지 마세요.

포함하지 않을 항목:

- 토큰, 비밀번호, 키, 자격 증명
- 개인을 식별할 수 있는 정보
- 내부 전용 시스템 주소, 계정, 비공개 운영 정보
- 기타 개발 관련 민감 자산
